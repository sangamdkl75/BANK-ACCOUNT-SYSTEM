# Bank Account System

A beginner-friendly Python project demonstrating Object-Oriented Programming (OOP).

## Features
- Create a bank account
- Deposit money
- Withdraw money
- Check the current balance
- Display account details
- Encapsulation using a private balance attribute

## Concepts Practiced
- Classes and objects
- Constructor (`__init__`)
- Instance methods
- Encapsulation
- Conditional statements

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```

Replace `main.py` with your actual Python filename if it differs.
